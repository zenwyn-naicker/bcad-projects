# BCAD Projects

Software projects from my Bachelor of Computer and Information Sciences in Application Development (BCAD), completed at Emeris Durban North (formerly Varsity College) between 2024 and 2026. They range from first-year Java applications to final-year full-stack, cloud and mobile systems, several of them built in a team of four.

Each project's README covers its features, architecture, setup and tests.
